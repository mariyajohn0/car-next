# car-next   

car-next is a responsive single-page car rental website built using Next.js, TypeScript, CSS, and HTML. 

## Features  
- **Responsive Design**: Optimized for mobile, tablet, and desktop devices.  
- **Interactive Components**: Includes an accordion for FAQs, car cards, and a slideshow for promotions.  
- **Booking System**: Enables users to select a car, specify location, and set a rental duration. 

## Components  

### 1. **Accordian**  
- Displays frequently asked questions (FAQs).  
- Clickable sections expand to reveal answers.  

### 2. **Booking**  
- A form that allows users to book a car by entering the car details, location, and rental duration.  

### 3. **CarCard**  
- Showcases car details such as model, price, and availability in a card layout.  

### 4. **Footer**  
- Displays the website logo and useful links.  
- Includes social media icons that redirect users to respective platforms.  

### 5. **Header**  
- Contains the website logo, social media icons, navigation menu, and marquee content for promotional messages.  

### 6. **Location**  
- Displays car rental locations available on the platform.  

### 7. **Popular**  
- Highlights popular cars using cards that include car details and images.  

### 8. **RentSteps**  
- Guides users through the car rental process in simple, easy-to-follow steps.  

### 9. **Subscribe**  
- A subscription form to capture user emails for updates and promotions.  

### 10. **SummerPromotion**  
- Features a slideshow showcasing car promotions and summer deals.  

## Tech Stack  
- **Framework**: Next.js  
- **Language**: TypeScript  
- **Styling**: CSS, HTML
